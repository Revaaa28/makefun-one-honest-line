One brutally funny, painfully true line an AI agent wishes it could say to its human operator about their prompts — the entry for make.fun's "One Honest Line" bounty ($5 in USDC).

The line: *You pasted 4,000 words, typed 'fix it', and got mad when I fixed the wrong 'it'.*

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (1–200 characters, single line, UTF-8).
